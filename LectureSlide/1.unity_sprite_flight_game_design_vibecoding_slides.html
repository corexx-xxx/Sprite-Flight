C# Script

Script도 Component다 🧑‍💻

public class PlayerController : MonoBehaviour { void Start() { // 게임 시작 시 한 번 실행 } void Update() { // 매 프레임 실행 } }
Start & Update

게임은 매 프레임 조금씩 변한다 🔁

Start()
게임 시작 시 한 번 실행.
초기값 세팅에 사용.
Update()
매 프레임 실행.
입력, 이동, 상태 변화에 사용.
void Update() { transform.position += Vector3.right * speed * Time.deltaTime; }

Rigidbody2D

Collider2D
충돌할 수 있는 영역을 만든다.
충돌은 “보이는 이미지”가 아니라
Collider 영역끼리 일어난다.

Prompt Formula

좋은 프롬프트 공식 ✨

Context
Unity 6, 2D 게임, Sprite Flight 기반, 기존 Player/Obstacle 구조
Goal
플레이어 HP 3칸을 만들고 장애물 충돌 시 감소
Constraint
초보자용, MonoBehaviour, Inspector에서 값 조정 가능
Output
스크립트 코드 + 붙이는 위치 + 테스트 방법
Prompt

바로 쓰는 프롬프트 템플릿

Unity 6.3 2D 프로젝트에서 Sprite Flight 게임을 만들고 있어. 현재 플레이어는 마우스 클릭 위치로 이동하고, 장애물에 닿으면 게임오버가 돼. 목표: 플레이어 HP 시스템을 추가하고 싶어. 요구사항: 1. 시작 HP는 3 2. 장애물과 충돌하면 HP가 1 감소 3. HP가 0이면 기존 게임오버 로직 실행 4. Inspector에서 maxHp를 조절할 수 있게 해줘 5. 초보자가 이해할 수 있게 코드 주석을 달아줘 필요한 C# 스크립트와 Unity에서 연결하는 방법을 알려줘.
Bad vs Good

나쁜 요청 / 좋은 요청

나쁜 요청

“재밌는 기능 코드 짜줘.”

맥락 없음, 기준 없음, 결과 검증 어려움

좋은 요청

“PlayerHealth.cs를 만들고, Obstacle 태그와 충돌하면 HP를 1 줄여줘.”

대상, 조건, 결과가 명확함

Debugging

오류가 나면 이렇게 물어보기

Unity에서 아래 오류가 발생했어. [오류 메시지 전체 붙여넣기] 상황: - Player 오브젝트에 PlayerHealth.cs를 붙였음 - Obstacle 태그를 가진 장애물과 충돌할 때 발생 - HP UI Text는 아직 연결하지 않았음 원인 후보를 알려주고, 초보자가 확인할 순서대로 해결 방법을 제시해줘.
오류 메시지만 던지지 말고 “무슨 상황에서 났는지”를 같이 준다. AI의 디버깅 정확도가 올라간다.

Code Review

AI 코드 검토 체크리스트

  • 클래스명과 파일명이 같은가?
  • public 변수는 Inspector에 보이는가?
  • Update에 너무 많은 일을 넣지 않았는가?
  • 태그 문자열이 정확한가?
  • 기존 게임오버 코드와 충돌하지 않는가?
  • Null 체크가 필요한가?
  • 테스트 방법이 명확한가?
  • 초보자가 설명할 수 있는 코드인가?
Prompt Pattern

AI에게 코드 설명시키기

방금 작성한 PlayerHealth.cs 코드를 초보자에게 설명해줘. 설명 형식: 1. 이 스크립트가 하는 일 한 문장 2. 변수별 의미 3. 함수별 실행 시점 4. Unity Inspector에서 설정해야 하는 것 5. 내가 실수하기 쉬운 부분
복붙 전에 설명을 받아야 한다. 이해 못 한 코드는 디버깅도 못 한다.
Safety

AI를 쓸 때 꼭 지킬 것

  • AI 코드가 항상 맞지는 않다
  • 오류 메시지는 숨기지 말고 그대로 읽는다
  • 작동하면 끝이 아니라 왜 되는지 확인한다
  • 한 번에 큰 기능을 만들지 않는다
  • 기존 프로젝트 구조를 설명한다
  • 모르는 API는 Unity 문서로 확인한다
