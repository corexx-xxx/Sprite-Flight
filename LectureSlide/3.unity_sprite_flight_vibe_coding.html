GOAL

실습 목표

오늘의 목표는 AI가 코드를 대신 작성하는 모습을 보는 것이 아닙니다. 게임 기능을 자연어로 정의하고, AI와 대화하면서 실제 Unity 프로젝트에 적용하는 개발 흐름을 익히는 것입니다.

배울 것

  • 게임 기능을 요구사항으로 설명하기
  • AI에게 단계별 구현 요청하기
  • 생성된 코드의 역할 확인하기
  • Unity에서 실행하고 결과 검증하기
  • 에러 메시지로 AI와 디버깅하기

중요한 기준

  • 한 번에 전체 게임을 생성하지 않습니다.
  • 기존 게임 구조를 최대한 유지합니다.
  • 한 기능씩 작게 추가하고 바로 실행합니다.
  • AI 답변을 그대로 믿지 않고 결과를 확인합니다.

게임 플레이 방식은 그대로 유지하면서
전체 테마를 우주 배경으로 바꾸고 싶어.

어떤 GameObject와 Sprite를 변경하면 되는지

확인할 것

DEMO 03

GameManager를 만들고 최고 점수 저장하기

이 단계부터 실제 코드 구조를 확장합니다. 처음에는 GameManager 스크립트가 없는 상태에서 시작합니다.

문제 정의

“게임을 다시 시작하면 점수가 사라진다. 최고 기록을 계속 저장하려면?”

AI에게 요청

Unity 2D 게임을 만들고 있어.

현재 게임에는 score가 있지만
게임을 다시 시작하면 점수가 초기화돼.

다음 기능을 추가하고 싶어.

1. 최고 점수 저장
2. 게임을 다시 실행해도 유지
3. 현재 점수와 최고 점수를 화면에 표시

현재 프로젝트에는 GameManager가 없어.

초보자가 따라할 수 있도록
필요한 GameObject와 C# Script부터 하나씩 만들어줘.

한 번에 전체 코드를 주지 말고 단계별로 진행해줘.

구현 순서

  1. Hierarchy에 GameManager GameObject 생성
  2. GameManager.cs 생성
  3. 현재 점수 값을 관리하도록 작성
  4. PlayerPrefs를 이용해 최고 점수 저장
  5. UI Text와 연결
  6. Play → 점수 획득 → 재시작 → 최고 점수 유지 확인
코드가 동작하더라도 “왜 static을 썼는가?”, “PlayerPrefs는 어디에 저장되는가?”처럼 생성된 코드의 핵심 역할을 반드시 확인합니다.
DEMO 04

AI와 함께 디버깅하기

바이브코딩에서 가장 중요한 과정 중 하나입니다. Console 에러가 나오면 에러를 숨기지 말고 그대로 활용합니다.

에러가 발생했을 때

Unity에서 아래 오류가 발생했어.

[Unity Console Error 붙여넣기]

방금 작성한 GameManager.cs를 적용한 이후 발생했어.

1. 에러 원인을 먼저 설명해줘.
2. 문제가 발생한 코드 위치를 알려줘.
3. 전체 코드를 다시 작성하지 말고 수정해야 할 부분만 알려줘.

AI에게 같이 전달하면 좋은 정보

  • Console 에러 전체 문장
  • 발생한 Script 이름
  • 해당 Script의 관련 코드
  • Unity에서 어떤 행동 후 문제가 발생했는지
DEMO 05

점수에 따라 난이도 증가시키기

최고 점수가 정상 동작하면 게임의 재미를 높이기 위해 난이도 시스템을 추가합니다.

요구사항 예시

  • 5점마다 난이도 한 단계 상승
  • 장애물 이동 속도 증가
  • 속도는 무한히 증가하지 않도록 제한
  • Inspector에서 기본 속도와 증가량 조절

AI에게 요청

현재 Sprite Flight 게임에는 score가 있어.

score가 증가하면 게임 난이도가 올라가게 만들고 싶어.

조건:
- 5점마다 난이도가 한 단계 증가
- 장애물 이동 속도가 증가
- 너무 어려워지지 않도록 최대 속도 제한
- 현재 난이도 설정을 Unity Inspector에서 조절 가능

기존 구조를 최대한 유지하면서 구현 방법을 알려줘.

먼저 설계를 설명하고,
그 다음 필요한 코드 변경을 단계별로 작성해줘.
포인트: 바로 코드를 요구하지 않고 “먼저 설계”를 요청하면 AI가 어떤 구조로 기능을 추가하려는지 먼저 검토할 수 있습니다.

학생 아이디어를 즉석에서 구현하기

마지막에는 새로운 기능 하나를 정해서 그 자리에서 AI와 함께 구현합니다.

아이디어 예시

  • Shield 아이템
  • 2배 점수 아이템
  • 일시 정지
  • 캐릭터 선택
  • 배경 테마 랜덤 변경
  • 보스 장애물

좋은 기능의 조건

  • 10~20분 안에 구현 가능한 범위
  • 기존 게임 구조를 완전히 바꾸지 않음
  • 게임을 실행하면 변화가 바로 보임

Shield 예시 프롬프트

현재 Unity Sprite Flight 게임에
Shield 아이템을 추가하고 싶어.

Player가 Shield를 먹으면
5초 동안 장애물에 한 번 충돌해도 죽지 않게 해줘.

조건:
- 현재 프로젝트 구조를 크게 변경하지 않는다.
- 필요한 GameObject와 Script를 먼저 설명한다.
- 구현 순서를 단계별로 알려준다.
- 한 단계 적용 후 테스트할 수 있도록 나눠서 설명한다.
